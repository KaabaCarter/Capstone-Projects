# JobTrac

## 1. Project Title

**JobTrac** — A job application tracking and interview management application.

## 2. Problem Statement

Finding a job can be stressful and difficult to organize, especially when applying to many positions across different platforms. Applicants may need to keep track of job applications, interview dates, job statuses, schedules, and follow-up messages.

JobTrac addresses this problem by providing a centralized platform where users can manage their job search and easily access their application history.

## 3. Proposed Solution

JobTrac is a desktop application designed to organize and simplify the job search process. Users will be able to enter and manage information such as:

* Job title and company
* Job description
* Salary/pay
* Application date
* Interview dates
* Job status
* Notes and additional information

Applications will be organized by status, such as **Applied, Interviewing, Offered, and Denied**.

The application will also provide scheduling and reminder features to help users manage interviews and important deadlines. An availability section will allow users to keep track of their available times when scheduling interviews.

## 4. Project Objectives

The primary objectives of JobTrac are to:

1. Help users schedule and manage interviews.
2. Track the status of job applications.
3. Organize job applications in one centralized location.
4. Add interviews and important dates to calendars and provide reminders.
5. Assist users with drafting or sending messages related to job opportunities.

## 5. Expected Outcome

The expected outcome is a functional desktop application that allows users to manage their job search in one place.

JobTrac will help users:

* Organize job applications
* Track application progress
* Manage interview schedules
* Set reminders for important events
* Maintain a history of their job search
* Manage communication with potential employers

## 7. Initial Project Plan

### Phase 1 — Application Design

* Determine the information users need to enter for each job application.
* Design the application's user interface.
* Plan the main dashboard and navigation.
* Determine how applications, interviews, and reminders will be displayed.

### Phase 2 — Database Development

* Design the database structure.
* Create tables for job applications and related information.
* Implement SQLite database functionality.
* Connect the database to the Python application.

### Phase 3 — Application Development

* Develop the main application using Python and PyQt6.
* Implement job application tracking.
* Add job status categories.
* Implement interview scheduling and availability.
* Add calendar and reminder functionality.
* Integrate the OpenAI API for job-related message drafting.

### Phase 4 — Testing

* Test each feature individually.
* Enter sample job applications to test database functionality.
* Test interview scheduling and reminders.
* Identify and fix bugs.
* Test the application's overall usability.

### Phase 5 — Finalization

* Improve the user interface.
* Optimize application functionality.
* Complete final testing.
* Prepare documentation and the final project presentation.

## 8. Project Goal

**JobTrac aims to make the job search process easier by giving users one centralized application to track jobs, manage interviews, organize schedules, and stay on top of their applications.**
